# Shives

Le planning des petits restaurants indépendants, fait en un clic.

Next.js · Tailwind CSS · Supabase · Vercel · Stripe

## Démarrer en local

1. Installer Node.js (version 22 ou plus).
2. `npm install`
3. Copier `.env.example` en `.env.local` et remplir les clés Supabase.
4. `npm run dev` puis ouvrir http://localhost:3000

## Commandes

- `npm run dev` : lance le site en local
- `npm run build` : vérifie que tout compile
- `npm test` : lance les tests
